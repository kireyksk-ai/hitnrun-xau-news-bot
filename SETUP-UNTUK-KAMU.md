# Satu langkah pengaturan

1. Di grup HitnRun FX, kirim pesan: `/start@HitnRunXAUAlert_bot`.
2. Buka folder proyek ini, lalu klik dua kali `JALANKAN-SETUP.cmd`. Jendela pengaturan akan tetap terbuka.
3. Masukkan tiga key yang sudah kamu buat: OpenAI, token Telegram yang baru, dan NewsAPI. Ketiganya tidak tampil di layar saat ditempel.
4. Skrip akan membuat file rahasia `.env`. Saat bot dijalankan, ia mencari ID grup dari pesan `/start` tersebut.

Jika Windows memberi peringatan keamanan, pilih **Run anyway** hanya bila file yang dibuka adalah `setup.ps1` dari folder proyek ini.
